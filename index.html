03

这个站点本身也是一件作品：单文件、零依赖的前端实验。 全部样式手写，不加载任何外部字体、脚本或图片，断网也能完整打开。 这里记录它的实现方式与部署链路，作为我的开发笔记。

技术栈
HTML + CSS（单文件，无框架）
部署
GitHub Pages · main 分支根目录
域名
suisuinian.loc.cc · CNAME 接入
主题
深色单色 + 强调色，预留浅色切换
D1

零依赖前端

整站一个 HTML 文件，样式全部写在 <style> 里；用 CSS 变量管理配色，媒体查询处理窄屏布局与动效偏好降级。

前端 · 手写
D2

静态部署链路

仓库根目录放 index.html 与 CNAME 文件，GitHub Pages 从 main 分支构建；域名用 CNAME 指向 Pages，并补一条 www 记录满足证书校验。

DevOps · Pages
D3

DNS 与证书笔记

一次完整排障记录：DNSSEC 信任链断裂导致校验失败、免费后缀共享证书配额的限制、以及 TXT 归属验证与限频的正确处理方式。
